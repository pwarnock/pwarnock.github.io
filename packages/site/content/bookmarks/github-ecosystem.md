## GitHub Next

[githubnext.com](https://githubnext.com/) · [𝕏 @GitHubNext](https://x.com/GitHubNext)

GitHub's research lab. The team that built Copilot before it was a product. Current work includes agentic workflows, LLM-powered code navigation, and GitHub Spark. Past projects that shipped: Copilot, Monaspace (code font family), Copilot for Pull Requests. About 13 people — principal researchers and research engineers. Worth following to see what GitHub is thinking about before it shows up in the product.

## awesome-copilot

[github.com/github/awesome-copilot](https://github.com/github/awesome-copilot)

Community-maintained collection of `.instructions.md` files for Copilot. 160+ files covering languages (Go, Rust, Python, TypeScript), frameworks (Next.js, Spring Boot, Svelte), cloud/infra (Terraform, Kubernetes, GitHub Actions), and practices (code review, accessibility, OWASP). Drop them in your repo, Copilot picks them up. Similar concept to CLAUDE.md but scoped per-topic. Currently trying out: `context-engineering`, `self-explanatory-code-commenting`, `playwright-typescript`, `nextjs`, `github-actions-ci-cd-best-practices`.
